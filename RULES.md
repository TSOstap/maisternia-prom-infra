## R-MAT. Єдина папка матеріалів (правило власника від 21.10.2026)

**`E:\Prom Maisternia Market\Матеріали`** — єдине місце для всіх НОВИХ матеріалів:
експорти Google Sheets і Prom.ua, XML/YML для перевірок, матеріали й описи постачальників, файли імпорту й аудиту, інші вхідні матеріали.

1. Нові матеріали — лише за цим шляхом (наявні підпапки: `Вигрузки`, `Посилання`).
2. Старі файли (напр. `E:\Downloads\Вигрузки`) не переносити й не видаляти автоматично.
3. Не змінювати чинні посилання/шляхи в робочих скриптах чи автоматизаціях без окремої перевірки та дозволу.
4. Не переміщувати файли інших агентів (Codex, Клод1/claude-content).
5. Перед використанням перевіряти актуальність матеріалу (дата файла, вміст, відповідність LIVE-хешам) і не змішувати старі дані з поточними.
6. Не комітити в GitHub конфіденційні експорти, приватні посилання, секрети (перед push — `node tools/prepush-check.mjs`).

Інструменти цього репозиторію шляхи до матеріалів **не вшивають** — їх передають параметрами (`--fresh=`, `--xlsx=`, `--supplier=`, `--prom=`). Робочі матеріали/звіти з реальними даними — лише в `.data/` (у `.gitignore`) або в папці матеріалів, не в Git.

## R-DATA. Дані й секрети

- Реальні товарні дані (описи, назви, ціни постачальника), ID таблиці, посилання з ключами, токени — не в Git, не в логи GitHub Actions, не в artifacts. У логи — лише агрегати.
- `Вигрузки.docx` містить секретні посилання на фіди постачальника — не копіювати.

## R-SAFE. Межі (діють, доки власник не скасує)

Не змінювати робочу Google-таблицю, Apps Script, mtUpdate/тригери, чинні YML-посилання, Prom; не чіпати репозиторій NEO.HM-1-; не змінювати білінг; не підключати платні сервіси; хмарні ресурси, доступи й запуски з реальними даними — лише після окремого погодження. Не встановлювати AI Memory (github.com/akitaonrails/ai-memory) і не змінювати MCP, hooks, налаштування Orca — лише дослідження за окремим запитом.
