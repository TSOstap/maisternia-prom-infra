# Реєстр рішень і зауважень власника щодо карток товарів

Найновіші — зверху. Новіше рішення має пріоритет. Позначки:
- **[ЗАМІНЕНО ← дата]** — рішення замінене пізнішим (вказано яким);
- **[СКАСОВАНО]** — скасоване без заміни;
- **[ІСТОРИЧНЕ]** — правило старої системи (Excel / Apps Script / конвеєр `Інструменти пром`). Для нової системи не підтверджене, наведено для контексту.

Коди джерел — як у `RULES.md` («Позначення джерел»). Цитати власника — дослівно, скорочення позначено «…».
Наскрізний покажчик за Offer ID — у кінці файлу.
