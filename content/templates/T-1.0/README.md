## 1. Структура

```
[сірий блок] <div class="ck-alert"><span class="ck-alert__title"></span>
   [синій блок] <div class="ck-alert ck-alert_theme_blue"><strong>Назва товару</strong> &mdash; вступ</div>
   абзаци <p>…</p>
   <p>&nbsp;</p>

```

## 2. Правила

| № | Правило |
|---|---|
| Ш1 | Увесь текст — усередині зовнішнього `<div class="ck-alert">` (сірий блок). Після нього — `<p>&nbsp;</p>` |
| Ш2 | Перший елемент усередині — синій блок `ck-alert ck-alert_theme_blue`: `<strong>Назва</strong> &mdash; вступ`. **Без кольорових фрагментів тексту** (жодних `style` з кольором) — рішення власника 29.10 |
| Ш3 | Після синього блоку — один або кілька абзаців `<p>`, потім `<p>&nbsp;</p>` |
| Ш4 | Заголовок блоку — **жирний, 16 px, жирність явна** (рішення власника 29.10): `<p><span style="font-size:16px"><strong style="font-weight:bold">Текст</strong></span></p>`. Текст під заголовком — без змін розміру. Чому явна: жирність лише від `<strong>` зникає там, де CSS сайту скидає `strong` (перевірено в Chromium: 400 замість 700); інлайн-стиль переважає такий CSS, а якщо стилі зрізано — лишається звичайна дія `<strong>` |
| Ш5 | Списки функцій і застережень: `<li><strong>Підпис:</strong> текст</li>`. Комплектація: `<li>предмет</li>` без підписів |
| Ш6 | Назви й порядок блоків — за товаром; блоки, для яких у тексті власника немає даних, не додаються |
| Ш7 | Символи — як у редакторі Prom: `&quot;` (дюйми: `12&quot;`, `1/4&quot;`), `&mdash;`, `&ndash;` (діапазони), `&middot;` (А&middot;год), `&#39;` (апостроф), `&nbsp;` |
| Ш8 | Дозволені теги: `div`, `span`, `strong`, `p`, `ul`, `li`. Атрибути: лише `class` (`ck-alert`, `ck-alert__title`, `ck-alert ck-alert_theme_blue`) і в заголовках — `style="font-size:16px"` на `<span>` та `style="font-weight:bold"` на `<strong>`. Інших стилів і таблиць немає |
| Ш9 | Без службових приміток («Технічні дані: (якщо потрібно залишити:»), без хвостових `&nbsp;` у пунктах, без порожніх абзаців поза Ш1 / Ш3 |
| Ш10 | RU — та сама структура, теги, кількість пунктів, числа, дюйми, коди моделей; перекладаються лише слова. Постійні заголовки: «Режими роботи та ключові функції» → «Режимы работы и ключевые функции»; «На що звернути увагу» → «На что обратить внимание»; «Технічні характеристики» → «Технические характеристики»; «Комплектація» → «Комплектация» |
| Ш11 | **«Технічні характеристики»** (рішення власника 29.10) — структурований список із жирними назвами параметрів, без таблиць: `<li><strong>Параметр:</strong> значення</li>`. Місце — перед «Комплектацією». **Блок додається ТІЛЬКИ тоді, коли такий блок із даними є у вихідному описі власника** (рішення 29.10); самостійно — ніколи, навіть зі значень, що є в тексті чи картці |

Перевірку Ш2, Ш4, Ш8 і Ш11 автоматизовано в `tools/check-description.mjs`.
