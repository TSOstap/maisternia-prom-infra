# Етап C1 — приватний репозиторій GitHub і вимірювання на справжньому runner

Стан: **ВИКОНАНО 21.10.2026** за дозволом власника. Репозиторій https://github.com/TSOstap/maisternia-prom-infra (PRIVATE). Результати — COSTS.md, розділ 2.1.

## Мета

Виміряти фактичний час, пам'ять і хвилини GitHub Actions на стандартному безплатному runner (2 vCPU / 8 GB для приватних репо). Тоді прогноз у COSTS.md спиратиметься на вимір, а не на оцінку.

## Що НЕ входить у C1

- жодних секретів GitHub (адреса постачальника, Google, Cloudflare);
- жодних реальних даних: у репозиторії лише код, тести, синтетика й документи; `.data/` у `.gitignore`;
- розклад `schedule` лишається вимкненим (закоментований);
- Prom, Google Sheets, Apps Script, YML не зачіпаються;
- R2/Worker не створюються (це C3).

## Що буде опубліковано в приватний репозиторій

Файли, які відстежує git (`git ls-files`, 55+), включно з:
- `reference/apps-script-live/*.gs` — копії живого коду без секретів;
- документи з агрегатами й Offer ID (без описів, цін постачальника, посилань і ключів).

`tools/prepush-check.mjs` блокує push, якщо знайде:
- `.data/`, xlsx, реальний YML або файли >5 МБ;
- шаблони секретів: hash_tag, /exec-адреси, ключі, токени, service account;
- хоча б один невдалий тест.

Приватні шаблони (наприклад, ID робочої таблиці) передаються лише змінною `PREPUSH_EXTRA_PATTERNS`, а не файлом.

## Перевірено локально (21.10)

- У чинному репозиторії `TSOstap/maisternia-market-prom` немає `.github/workflows` — він не витрачає хвилин Actions. Ліміт 2000 хв/міс спільний для всіх приватних репозиторіїв акаунта.
